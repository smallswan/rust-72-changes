一、思维方法论

三种核心思维

思维说明
数学思维数学是科学的语言，是最重要的理论工具
工具思维计算机是最重要的工程应用工具
工程思维将理论工具应用到实际问题中的思维方式

人类学习的一般规律

  • 从特殊到一般：先接触具体实例，再归纳总结出普遍规律
  • 从直觉到抽象：先靠感官感知，再上升到抽象推理
  • 从已知到未知：依托已有知识同化新知识
  • 从感性到理性：先感性观察，再理性分析

费曼学习法

如果你不能用简单的话把某个概念讲清楚，说明你还没有真正理解它。—— 理查德·费曼

四个步骤：

  1. 确定目标：写下你想学习的概念
  2. 模拟教学：用最简单的语言解释给一个8岁的孩子听
  3. 发现盲点：卡住的地方回到原始材料重新学习
  4. 简化与类比：用一个生动的类比让外行也听懂

九、Rust Playground 运行原理与预置 crates

# 将 markdown 中的代码块发送到 Rust Playground API
curl -X POST https://play.rust-lang.org/evaluate.json \
  -H "Content-Type: application/json" \
  -d @rust_code.json

Playground 会把代码发到远端沙箱编译运行，无需本地安装 Rust 工具链。它预置了大量常用 crate 及其全部依赖，在代码顶部用注释声明即可使用：

▶ 在 Rust Explorer 中运行
/*
[dependencies]
rand = "0.10"
*/
fn main() {
    println!("{}", rand::random::<u8>());
}

局限：版本由 Playground 统一预置，不能随意指定；依赖系统原生库（如 OpenSSL）的 crate 一般不可用。适合算法验证、语法实验和小型数学计算。

9.1 查询当前支持的 crates

预置清单会随 Playground 更新而变化。用下面命令获取实时数据（返回 JSON）：

curl -sS https://play.rust-lang.org/meta/crates

每个元素形如 {"name":"serde","version":"1.0.229","id":"serde"}。统计总数：

curl -sS https://play.rust-lang.org/meta/crates | python -c "import json,sys; d=json.load(sys.stdin)['crates']; print('记录数:',len(d),'去重后:',len({c['name'] for c in d}))"

本次查询（2026-11-28）结果：534 条记录、488 个不同的 crate。下面按用途列出常用库及其预置版本。

十一、人机交互方式

方式说明
GUI图形用户界面，用户友好
CLI命令行界面，高效精确
代码人类使用代码编写程序与机器交互

成千上万的科学家实现 0→1 的发现，数以千万的工程师创造、集成大量的工具，数以亿计的普通人利用工具。

一个伟大的工具，能够深入和广泛应用在各行各业，一个重要的前提是成本足够低、效率足够高。

十二、AI：所有人可用的强大工具

过去电脑花了二十年才改变工作方式，而 AI 用自然语言交互，主动适应人类，无需人们重新学习操作逻辑。

工具的历史，就是不断降低使用门槛的历史。当门槛低到「会说话就会用」，工具便不再是少数人的专利。

第十一节说到人机交互从 GUI 到 CLI 再到代码——每一次演进，都在效率与门槛之间做取舍。AI 带来的自然语言交互，第一次同时把两头都占了：像 CLI 一样精确，像 GUI 一样无需背诵。

12.1 从「学工具」到「说需求」

交互方式使用门槛效率主要受众你把精力花在哪
GUI 图形界面低中所有人找按钮、记位置
CLI 命令行中高运维、开发者背命令、记参数
代码高最高程序员学语法、调 BUG
自然语言 / AI极低高所有人把需求说清楚

前三种方式里，人是主动去适应机器的：你得先学会它的语言，它才肯替你干活。AI 把这个方向倒了过来——机器来适应人。你说「不要太甜、尽快送到」，它理解为「少糖、最近门店」；你说重庆话，它也听得懂。门槛从「掌握语法」降到了「表达意图」。

这是一次性质的变化：过去的工具放大的是操作能力，AI 放大的开始是意图本身。

12.2 三个「降到」：为什么是现在

AI 不是今天才聪明，而是今天才用得起、够得着、能干活。

维度变化佐证
成本降到同等推理水平的调用成本，两年间降至约 1/280斯坦福《2025 年人工智能指数报告》；GPT-4 同等性能从 2022 年底约 20 美元/百万 token，降至 2025 年底约 0.40 美元
门槛降到从「你问我答」进化到「理解目标→拆解任务→调用工具→自主执行」2026 年春节，中老年人通过健康 AI 应用、语音控家电等场景大规模接入，方言识别成为标配
能力升到从「会聊天」转向「能干活」：推理（Reasoning）+ 行动（Action）双循环新一代模型可自主规划、调用工具、反思修正；这正是附录8 里 Agent / Skill / MCP 三件套解决的问题

成本下降与用户增长互为因果：2026 年初 ChatGPT 周活跃用户约 9 亿；同期豆包、千问、深度求索的国内月活分别约 3.4 亿、1.7 亿、1.3 亿。价格走低让个人开发者和中小企业都用得起，用户规模又摊薄了成本。这个正循环，把 AI 从实验室推成了日常服务。

12.3 智能正在「水电化」

当一样东西便宜到按量计费、随处可取，它就从「产品」变成了「基础设施」。

  • 可计量：词元（token）成为智能的最小计费单位。智能第一次像电力一样，可以被计量、定价和交易——电价按千瓦时，智能按词元。
  • 可及：算力与数据基础设施「水电化」，按需付费。开源模型与闭源模型的性能差距缩小，本地运行一个够用的模型，一条命令即可。
  • 可组装：一个人 + AI，就能完成过去需要一个跨职能团队才能做的事——写脚本、做视觉、调代码、出分析报告。于是有了「超级个体」：传统生产力 = 人力 + 资本 + 土地，而新的生产力 = 个体创造力 + AI 算力 + 数据 + 数字基础设施。

回到本章开头的话：「工具思维」认为计算机是最重要的工程应用工具。今天这句话可以往前推一步——AI 正在成为那个「最重要的工具」的下一形态：它不只是被使用，还能替你把别的工具串起来用。

12.4 也别把它神化

普及的广度和应用的深度之间，仍有距离。麦肯锡 2025 年的全球调查显示，多数企业已在至少一项业务中使用 AI，但真正实现规模化应用的仍是少数。

问题原因应对
用了，却没真正用透停留在单点功能，各类工具彼此「聋哑」打通场景与协议，让 AI 成为连接中枢，而非孤岛应用
错误信息被当成答案生成内容流畅但可能失真，老年人等群体甄别能力偏弱关键结论交叉验证；保留人在环（human-in-the-loop）
隐私与数据主权免费服务往往以数据作为交换敏感信息用本地或私有部署；明确数据边界
把「会说」当成「会做」自然语言掩盖了能力的真实边界用可执行的结果验收，而非模型自评（见附录8 的踩坑指南）

第十节那句语录在这里依然成立：「科学技术是一把双刃剑，既可以造福人类，也可以伤害人类，关键是掌握在谁的手中，用它来干什么。」 AI 放大的是人的意图——包括好的和坏的。工具越强，使用者的判断力越重要。

一个伟大的工具，前提是成本足够低、效率足够高；而一个真正普惠的工具，还要让每个人都能用好它。AI 正在从「可用」走向「人人可用」，剩下的那一半，是教育、是规范，也是每个使用者自己的判断力。
