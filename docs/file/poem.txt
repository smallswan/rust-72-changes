# 中国著名军事将领
## 先秦时期

    孙武 - 春秋齐国，著《孙子兵法》，辅佐吴王阖闾破楚

    廉颇 - 战国赵国，赵之名将，负荆请罪，长平之战后抗燕有功

## 秦汉时期

    蒙恬 - 秦朝，北逐匈奴，修筑长城，威震朔方

    章邯 - 秦末，率骊山刑徒镇压陈胜起义军，后降项羽

    张良 - 西汉，谋略家，佐刘邦定天下，"运筹帷幄之中，决胜千里之外"

    萧何 - 西汉，虽以治国闻名，但保障后勤、稳定后方为军事胜利之基

    周勃 - 西汉，随刘邦起兵，后平定诸吕之乱，恢复刘氏江山

    周亚夫 - 西汉，周勃子，平定七国之乱，治军严明，"细柳营"闻名

    卫青 - 西汉，七击匈奴，收复河套，官至大将军

    霍去病 - 西汉，"封狼居胥"，饮马瀚海，年少成名，冠军侯

    李广 - 西汉，"飞将军"，数击匈奴，勇猛过人但命途多舛

    赵充国 - 西汉，平定西羌，屯田安边，老成持重

    刘秀 - 东汉开国皇帝，昆阳之战以少胜多，统一天下

    冯异 - 东汉，"大树将军"，征讨赤眉军，功高不矜

    马援 - 东汉，"马革裹尸"，平定交趾、西羌，伏波将军

    班超 - 东汉，"投笔从戎"，经营西域三十余载，定远侯

    窦宪 - 东汉，"燕然勒功"，大破北匈奴，刻石记功而还

    郭嘉 - 魏，曹操首席谋士，"十胜十败论"，早逝

    张辽 - 魏，合肥之战以八百破十万，威震江东

    徐晃 - 魏，长驱直入击败关羽，治军严谨

    邓艾 - 魏，偷渡阴平，灭亡蜀汉

    诸葛亮 - 蜀汉，隆中对、平定南中、六出祁山，"鞠躬尽瘁"

    关羽 - 蜀汉，"万人敌"，水淹七军，威震华夏

    张飞 - 蜀汉，当阳桥喝退曹军，义释严颜

    赵云 - 蜀汉，长坂坡救阿斗，汉水之战"一身是胆"

    马超 - 蜀汉，西凉猛将，曾逼曹操"割须弃袍"

    魏延 - 蜀汉，镇守汉中，提出"子午谷奇谋"

    周瑜 - 吴，赤壁之战大破曹操，火烧连营

    陆逊 - 吴，夷陵之战火烧连营七百里，败刘备

    吕蒙 - 吴，白衣渡江，袭取荆州，击杀关羽

    甘宁 - 吴，"锦帆贼"出身，百骑劫曹营

    杜预 - 西晋，文武兼备，参与灭吴之战，注《左传》

    王濬 - 西晋，益州刺史，自蜀伐吴，"王濬楼船下益州"

    刘琨 - 西晋，闻鸡起舞，坚守并州十年，抗击刘聪

    祖逖 - 东晋，中流击楫，北伐收复黄河以南

    谢玄 - 东晋，淝水之战以八万破前秦百万，北府兵统帅

    刘牢之 - 东晋，北府兵名将，淝水之战前锋

    刘裕 - 南朝宋开国皇帝，北伐灭南燕、后秦，"气吞万里如虎"

    檀道济 - 南朝宋，"唱筹量沙"，北伐功高震主，被杀前叹"乃坏汝万里长城"

    韦叡 - 南朝梁，钟离之战败北魏，"韦虎"之称

    陈庆之 - 南朝梁，白袍军数千人北伐，攻占洛阳，"千军万马避白袍"

    尔朱荣 - 北魏，河阴之变，镇压葛荣起义

    高欢 - 东魏权臣，沙苑之战败于宇文泰

    宇文泰 - 西魏权臣，创建府兵制，与高欢对峙

    斛律光 - 北齐，"落雕都督"，抗击北周，与韦孝宽对峙

    韦孝宽 - 北周，玉璧之战败高欢，献"金蝉计"除斛律光

    慕容垂 - 后燕开国皇帝，前秦名将，淝水之战后复国
