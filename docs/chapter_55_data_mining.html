Rust七十二变（Rust 72 Changes）

第五十五 数据挖掘

数据挖掘（Data Mining）是从大规模数据集中自动发现隐藏的、有价值的模式与知识的过程。它是连接数据库、统计学和机器学习的桥梁，在商业决策、科学研究、医疗健康、金融风控等领域有着广泛应用。Rust 以其卓越的性能和内存安全特性，正逐渐成为构建高性能数据处理管线的优选语言。本章将系统介绍数据挖掘的核心概念、经典算法，并展示如何用 Rust 实现关键的数据挖掘任务。

一、什么是数据挖掘

1.1 定义与目标

数据挖掘是从大量数据中提取隐含的、先前未知的、潜在有用信息的过程。它不是简单的数据查询或统计，而是通过算法自动发现数据中隐藏的模式（Pattern）、关联（Association）、异常（Anomaly）和趋势（Trend）。

概念说明
数据（Data）原始的事实和数字
信息（Information）经过组织和结构化的数据
知识（Knowledge）从信息中提炼出的规律和洞察
智慧（Wisdom）将知识应用于决策和行动

数据挖掘的核心目标是将数据转化为知识。

1.2 KDD 过程

数据挖掘通常是**知识发现（Knowledge Discovery in Databases, KDD）**过程的核心步骤之一。完整的 KDD 流程包括：

数据选择 → 数据预处理 → 数据变换 → 数据挖掘 → 模式评估 → 知识表示
步骤说明
数据选择从数据源中选取与任务相关的数据子集
数据预处理处理缺失值、噪声、异常值，保证数据质量
数据变换归一化、离散化、特征工程，使数据适合挖掘算法
数据挖掘应用算法提取模式
模式评估评估发现的模式是否有意义、有价值
知识表示以可理解的方式呈现挖掘结果

二、数据挖掘的核心任务

数据挖掘的任务可分为两大类：描述性任务和预测性任务。

2.1 描述性任务

描述性任务旨在发现数据中的内在结构和模式。

任务说明示例
聚类分析将数据划分为若干组，组内相似、组间相异客户分群、文档归类
关联规则发现数据项之间的共现关系购物篮分析：“买啤酒的人也常买尿布”
异常检测识别偏离正常模式的异常数据点信用卡欺诈检测、网络入侵检测
频繁模式挖掘发现数据中频繁出现的模式网页访问模式、序列模式

2.2 预测性任务

预测性任务利用已知数据预测未知属性或未来趋势。

任务说明示例
分类根据已有特征预测类别标签邮件垃圾过滤、疾病诊断
回归预测连续数值房价预测、销量预测
时间序列预测基于历史时序数据预测未来值股票走势、天气预报

三、经典数据挖掘算法

3.1 关联规则：Apriori 算法

Apriori 算法是挖掘频繁项集和关联规则的经典算法。其核心思想是：如果一个项集是频繁的，那么它的所有子集也必须是频繁的（Apriori 性质）。

关键指标：

指标公式含义
支持度（Support）$\text{sup}(X) = \frac{\text{包含 X 的事务数}}{\text{总事务数}}$项集出现的频率
置信度（Confidence）$\text{conf}(X \Rightarrow Y) = \frac{\text{sup}(X \cup Y)}{\text{sup}(X)}$规则的可靠程度
提升度（Lift）$\text{lift}(X \Rightarrow Y) = \frac{\text{conf}(X \Rightarrow Y)}{\text{sup}(Y)}$规则的实际关联强度
 
#![allow(unused)]
fn main() {
use std::collections::{HashMap, HashSet};

/// 统计候选项集的支持度计数
fn scan_transactions(
    transactions: &[HashSet<&str>],
    candidates: &[HashSet<&str>],
) -> HashMap<HashSet<String>, usize> {
    let mut counts: HashMap<HashSet<String>, usize> = HashMap::new();
    for candidate in candidates {
        let mut count = 0;
        for transaction in transactions {
            if candidate.is_subset(transaction) {
                count += 1;
            }
        }
        counts.insert(
            candidate.iter().map(|s| s.to_string()).collect(),
            count,
        );
    }
    counts
}

/// 生成频繁项集（简化版 Apriori）
fn apriori_frequent_itemsets(
    transactions: &[HashSet<&str>],
    min_support: f64,
) -> Vec<(HashSet<String>, f64)> {
    let total = transactions.len() as f64;

    // 第一步：找出所有频繁 1-项集
    let mut item_counts: HashMap<&str, usize> = HashMap::new();
    for t in transactions {
        for item in t {
            *item_counts.entry(item).or_insert(0) += 1;
        }
    }

    let frequent_1: Vec<HashSet<String>> = item_counts
        .iter()
        .filter(|(_, &count)| count as f64 / total >= min_support)
        .map(|(&item, _)| {
            let mut set = HashSet::new();
            set.insert(item.to_string());
            set
        })
        .collect();

    let mut result: Vec<(HashSet<String>, f64)> = frequent_1
        .iter()
        .map(|itemset| {
            let support = item_counts[&*itemset.iter().next().unwrap()] as f64 / total;
            (itemset.clone(), support)
        })
        .collect();

    // 后续步骤：逐步生成 k-项集（简化，仅展示 2-项集）
    let mut prev_frequent = frequent_1;
    let mut k = 2;

    loop {
        let mut candidates: Vec<HashSet<String>> = Vec::new();
        let prev_vec: Vec<&HashSet<String>> = prev_frequent.iter().collect();
        for i in 0..prev_vec.len() {
            for j in (i + 1)..prev_vec.len() {
                let mut candidate = prev_vec[i].clone();
                candidate.extend(prev_vec[j].clone());
                if candidate.len() == k && !candidates.contains(&candidate) {
                    candidates.push(candidate);
                }
            }
        }

        if candidates.is_empty() {
            break;
        }

        let candidate_refs: Vec<HashSet<&str>> = candidates
            .iter()
            .map(|c| c.iter().map(|s| s.as_str()).collect())
            .collect();

        let counts = scan_transactions(transactions, &candidate_refs);

        prev_frequent.clear();
        for (itemset, count) in &counts {
            let support = *count as f64 / total;
            if support >= min_support {
                result.push((itemset.clone(), support));
                prev_frequent.push(itemset.clone());
            }
        }

        if prev_frequent.is_empty() {
            break;
        }
        k += 1;
    }

    result
}
}

3.2 聚类分析：K-Means 算法

K-Means 是最常用的划分聚类算法。它将 n 个数据点划分为 k 个簇，使得每个点到其所属簇中心的距离之和最小。

算法步骤：

  1. 随机选择 k 个点作为初始簇中心
  2. 将每个点分配到最近的簇中心
  3. 重新计算每个簇的中心
  4. 重复步骤 2-3 直到收敛
#![allow(unused)]
fn main() {
/// 二维数据点
#[derive(Debug, Clone, Copy)]
struct Point {
    x: f64,
    y: f64,
}

impl Point {
    fn distance(&self, other: &Point) -> f64 {
        ((self.x - other.x).powi(2) + (self.y - other.y).powi(2)).sqrt()
    }
}

/// K-Means 聚类
fn kmeans(data: &[Point], k: usize, max_iters: usize) -> Vec<(Point, Vec<usize>)> {
    let n = data.len();
    // 初始化：选择前 k 个点作为初始中心
    let mut centroids: Vec<Point> = data[..k].to_vec();
    let mut assignments = vec![0usize; n];

    for _ in 0..max_iters {
        // 分配：将每个点分配到最近的簇中心
        let mut changed = false;
        for (i, point) in data.iter().enumerate() {
            let nearest = centroids
                .iter()
                .enumerate()
                .min_by(|(_, a), (_, b)| {
                    a.distance(point).partial_cmp(&b.distance(point)).unwrap()
                })
                .map(|(idx, _)| idx)
                .unwrap();
            if assignments[i] != nearest {
                assignments[i] = nearest;
                changed = true;
            }
        }

        if !changed {
            break; // 已收敛
        }

        // 更新：重新计算每个簇的中心
        let mut sums = vec![(0.0f64, 0.0f64); k];
        let mut counts = vec![0usize; k];
        for (i, point) in data.iter().enumerate() {
            let c = assignments[i];
            sums[c].0 += point.x;
            sums[c].1 += point.y;
            counts[c] += 1;
        }
        for (j, centroid) in centroids.iter_mut().enumerate() {
            if counts[j] > 0 {
                centroid.x = sums[j].0 / counts[j] as f64;
                centroid.y = sums[j].1 / counts[j] as f64;
            }
        }
    }

    // 组装结果
    let mut clusters: Vec<(Point, Vec<usize>)> = centroids
        .into_iter()
        .map(|c| (c, Vec::new()))
        .collect();
    for (i, &cluster_id) in assignments.iter().enumerate() {
        clusters[cluster_id].1.push(i);
    }
    clusters
}
}

3.3 异常检测：基于 Z-Score 的方法

异常检测旨在识别偏离正常模式的数据点。Z-Score 方法是一种简单有效的统计方法。

$$Z = \frac{X - \mu}{\sigma}$$

其中 $\mu$ 为均值，$\sigma$ 为标准差。$|Z| > 3$ 通常被视为异常点。

#![allow(unused)]
fn main() {
/// 计算均值
fn mean(data: &[f64]) -> f64 {
    data.iter().sum::<f64>() / data.len() as f64
}

/// 计算标准差
fn std_dev(data: &[f64]) -> f64 {
    let m = mean(data);
    let variance = data.iter().map(|x| (x - m).powi(2)).sum::<f64>() / data.len() as f64;
    variance.sqrt()
}

/// Z-Score 异常检测
fn detect_anomalies_zscore(data: &[f64], threshold: f64) -> Vec<(usize, f64, f64)> {
    let m = mean(data);
    let s = std_dev(data);
    let mut anomalies = Vec::new();

    if s == 0.0 {
        return anomalies;
    }

    for (i, &value) in data.iter().enumerate() {
        let z = (value - m) / s;
        if z.abs() > threshold {
            anomalies.push((i, value, z));
        }
    }
    anomalies
}
}

3.4 分类：决策树

决策树是一种直观的分类算法，通过一系列 if-then 规则对数据进行分类。构建决策树的关键是选择最优划分属性，常用指标包括：

指标公式/说明目标
信息增益（Information Gain）基于信息熵的减少量选择使熵减少最多的属性
基尼系数（Gini Index）$\text{Gini}(D) = 1 - \sum_{k=1}^{K} p_k^2$选择使基尼系数最小的属性

信息熵：

$$H(D) = -\sum_{k=1}^{K} p_k \log_2 p_k$$

其中 $p_k$ 是第 $k$ 类样本在数据集中的比例。

数据质量直接决定挖掘结果的好坏。“垃圾进，垃圾出”（Garbage In, Garbage Out）是数据挖掘领域的经典格言。

4.1 缺失值处理

策略说明适用场景

4.2 数据归一化

不同特征的量纲差异会影响算法效果，需要进行标准化处理。

方法公式说明
Min-Max 归一化$x’ = \frac{x - x_{\min}}{x_{\max} - x_{\min}}$映射到 [0, 1] 区间
Z-Score 标准化$x’ = \frac{x - \mu}{\sigma}$均值为 0，标准差为 1
 
#![allow(unused)]
fn main() {
/// Min-Max 归一化
fn min_max_normalize(data: &[f64]) -> Vec<f64> {
    let min = data.iter().cloned().fold(f64::INFINITY, f64::min);
    let max = data.iter().cloned().fold(f64::NEG_INFINITY, f64::max);
    let range = max - min;
    if range == 0.0 {
        return vec![0.0; data.len()];
    }
    data.iter().map(|x| (x - min) / range).collect()
}

/// Z-Score 标准化
fn zscore_standardize(data: &[f64]) -> Vec<f64> {
    let m = mean(data);
    let s = std_dev(data);
    if s == 0.0 {
        return vec![0.0; data.len()];
    }
    data.iter().map(|x| (x - m) / s).collect()
}
}

五、模型评估

5.1 分类评估指标

指标公式含义
准确率（Accuracy）$\frac{TP + TN}{TP + TN + FP + FN}$正确预测的比例
精确率（Precision）$\frac{TP}{TP + FP}$预测为正的样本中真正为正的比例
召回率（Recall）$\frac{TP}{TP + FN}$真正为正的样本中被正确预测的比例
F1 分数$2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}$精确率和召回率的调和平均

5.2 交叉验证

交叉验证（Cross-Validation）是评估模型泛化能力的标准方法。最常用的是 k 折交叉验证：将数据分为 k 份，依次用每一份作为验证集，其余 k-1 份作为训练集，取 k 次评估的平均值作为最终结果。

#![allow(unused)]
fn main() {
/// k 折交叉验证的索引划分
fn k_fold_indices(n: usize, k: usize) -> Vec<(Vec<usize>, Vec<usize>)> {
    let fold_size = n / k;
    let mut folds = Vec::new();

    for i in 0..k {
        let start = i * fold_size;
        let end = if i == k - 1 { n } else { (i + 1) * fold_size };
        let val_indices: Vec<usize> = (start..end).collect();
        let train_indices: Vec<usize> = (0..start).chain(end..n).collect();
        folds.push((train_indices, val_indices));
    }
    folds
}
}

6.2 使用 Linfa 进行聚类

Linfa 提供了多种机器学习算法的 Rust 原生实现。

▶ 在 Rust Explorer 中运行
/*
[dependencies]
ndarray = "0.16"
*/
use linfa::prelude::*;
use linfa_clustering::KMeans;
use ndarray::Array2;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    // 构造数据
    let data = Array2::from_shape_vec((6, 2), vec![
        1.0, 2.0,  1.5, 1.8,  5.0, 8.0,
        8.0, 8.0,  1.0, 0.6,  9.0, 11.0,
    ])?;

    let dataset = Dataset::from(data);

    // K-Means 聚类，k=2
    let model = KMeans::params(2)
        .max_n_iterations(100)
        .fit(&dataset)?;

    println!("簇中心:\n{}", model.centroids());

    // 预测新数据点的簇归属
    let prediction = model.predict(
        &Array2::from_shape_vec((1, 2), vec![2.0, 1.5])?
    );
    println!("新点所属簇: {:?}", prediction);

    Ok(())
}
