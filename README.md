# Rust七十二变（Rust 72 Changes）

> 以 Rust 编程语言为舟，溯计算机底层原理之源。

本书以 Rust 语言为实践工具，分上、中、下三卷，共七十二篇（美其名曰"七十二变"），由浅入深地讲解计算机科学的核心原理——从数据如何被编码，到运算如何被组织，再到秘密如何被守护。每章均辅以可运行的 Rust 代码，帮助读者在理解原理的同时掌握实战技能。

---

## 内容概览

全书分为三卷，层层递进，环环相扣：

| 卷 | 章节范围 | 主题 | 章数 |
|:---|:---|:---|:---|
| 上卷 | 第一 ~ 第十三 | 数据与编码 | 13 |
| 中卷 | 第十四 ~ 第四十 | 运算与算法 | 27 |
| 下卷 | 第四十一 ~ 第七十二 | 秘密与密码 | 32 |

### 上卷：数据与编码

探索计算机世界的"原材料"——从最基本的数字、字符、字节出发，逐步扩展到时间、图片、条码、二维码、音频、视频等复杂数据类型，最终探讨序列化、持久化与可视化等高级主题。

涵盖：数字、字符与编码、字节、时间、图片、条形码、二维码、音频、视频、万物皆可编码、序列化与反序列化、输入输出、数据与代码。

### 中卷：运算与算法

介绍各种数据如何通过运算与转换解决现实问题。从算术、关系、逻辑、位运算出发，深入到排序、搜索、哈希等经典算法，再扩展到人工智能、代数、几何、微积分、概率论、神经网络、自然语言处理、计算机视觉、强化学习和生成式 AI 等前沿领域。

涵盖：算术运算、关系运算、逻辑运算、位运算、交换/反转/旋转、类型转换、哈希、打包/拆包/压缩/解压、查询/检索/搜索、排序、Lambda 演算、人工智能、算法、代数、几何、行列式、矩阵、向量、函数、微积分、概率论、离散数学、神经网络、自然语言处理、计算机视觉、强化学习、生成式 AI。

### 下卷：秘密与密码

探讨如何通过密码技术实现数据的安全存储与传输。从口令和随机数出发，深入对称密码、非对称密码、哈希函数等核心密码学原语，再扩展到身份认证、授权、PKI、TLS、区块链、零知识证明、同态加密、量子密码等高级主题。

涵盖：口令、随机数、密钥、对称密码、非对称密码、不可逆密码、认证、授权、数字证书与 PKI、TLS/SSL、区块链、零知识证明、同态加密、量子密码学、无敌密码、终极密码。

### 附录

- 符号表速查

## 本书特色

- **原理为先**：每章从底层原理出发，讲解"为什么"而非仅仅是"怎么做"。
- **代码为体**：所有核心概念配以 Rust 代码实现，可直接在 [Rust Playground](https://play.rust-lang.org/) 或本地运行。
- **实战为要**：通过实战项目将分散的知识点串联成完整解决方案。

## 本地阅读

**方式一：使用任意 HTTP 服务器（推荐）**
```bash
# 使用 Python 启动本地服务器
cd book
python -m http.server 8080

# 或使用 miniserve
cd book
miniserve .
```

然后访问 `http://localhost:8080/book/index.html` 即可阅读。

> **注意**：直接以 `file://` 协议打开 `book/index.html` 可能导致部分资源加载异常（如 SQL.js 数据库页面），建议使用上述 HTTP 服务器方式浏览。
